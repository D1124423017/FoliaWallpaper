# Folia × Mineradio presentation

Mineradio original source, UI, Three.js particle shaders, camera logic and 3D shelf:

Source: https://github.com/XxHuberrr/Mineradio-paused
Pinned upstream commit: d43de565acabfdc1a9c9820a27e81a98ccbebcef.

This modified presentation replaces independent playback, account, search and startup
with a message bridge to the Folia core. Original source is retained under js/modules.
It removes the upstream updater, external Google Fonts and native desktop controls.
SonicTopography and SonicWorkshop are excluded pending separate compatibility and
license review. It does not represent those presets as supported features.

# 已知限制與驗證範圍

版本 `0.7.17-integration.4`，交付修訂 `license.1`。實測結果見 `VALIDATION.md` 與交付目錄 `FINAL-VALIDATION.md`；原始碼、安裝包及測試的雜湊見 `ARTIFACTS.json`。

- 僅提供 Windows x64 本機預覽版，安裝包未簽章，未自動發布到 GitHub 或 Steam Workshop。
- 播放來源沿用 Folia 原有支援來源；不能把 Spotify／YouTube 的外部跟隨模式稱為本播放器已接入其完整帳號串流。平台會員、地區、音源及帳號權限仍依各服務。
- 已使用使用者自行登入的網易雲帳號實測共享帳號、讀取歌單、收藏、加入歌曲及移除，測試資料均還原。未使用真實酷狗或 Navidrome 帳號驗證其遠端寫入；Omni 未提供線上歌單建立／刪除功能。
- 切換三種體驗保留同一播放核心；冷啟動沿用 Folia 的行為，恢復歌曲與佇列但保持暫停，不保存精確播放秒數。暫停有淡出，跳轉會恢復播放。
- Mineradio 保留原版 11 種支援預設、粒子舞臺、鏡頭、DIY 及 3D 歌單架。Sonic Topography／Sonic Workshop（7、8）的 preset 和 vendor 未交付；外部 AI 深度圖、MediaPipe 手勢模型及獨立自動混音未接入。
- Mineradio 的平台／Podcast 分頁使用共用歌曲搜尋；音質、快取及快捷鍵入口導向 Folia 設定。自訂使用 Folia 控制時，Mineradio 3D 歌單架隨原控制台隱藏，尚未拆為獨立可選元件。
- 主要介面已繁體化並補上常用臺灣用語；原版字體、色盤及部分專有名稱保留，歌曲和歌詞保持來源原文。未將所有原版選項逐項驗證為支援。
- Wallpaper Engine 桌布及背景服務保持獨立，播放器安裝包不會自行安裝或更新它們；需使用支援共用資料介面的新版桌布。Folia 原有 Rust 桌布輔助程式未納入本建置。
- 桌布本身不播放音樂。Wallpaper Engine 的焦點、全螢幕、其他音訊及休眠規則可以暫停桌布，播放器仍會播放；回到桌面恢復更新後會重新取得進度。測試暫時調整的規則會還原。
- 桌布經本機輪詢接收資料並以時鐘推算進度，暫停、跳轉及循環非零延遲；不能將診斷取樣時間稱為毫秒精度的畫面延遲量測。
- 外部播放器、不同版本 MV 或歌詞與音訊校正保留原來源限制，不保證每首歌均有正確逐字歌詞。原版模型按需下載，付費 AI API 需使用者自行設定，整合包不附私人金鑰。
- 本機長測不代表低規格裝置或所有歌曲均無效能問題；效能與記憶體取樣範圍按實際紀錄列明。
- 原先 26 項通知問題保留歷史；兩項實際交付缺口已改用附完整 MIT 的官方相容來源，原實作不再交付。建置依賴聯集的其他历史缺口和判定範圍見 NOTICE-GAPS.md；公開發佈前仍需提供同修訂完整原始碼的實際公開網址。

# Folia Mineradio 使用說明（第四階段預覽版）

這是 Folia 與 Mineradio 的整合預覽版，版本 `0.7.17-integration.4`，目前本機介面修訂 `ui.2`。`VALIDATION.md` 保留先前 `license.1` 的完整實測歷史；本次變更見 `UI-CHANGES.md`，既有功能限制見 `KNOWN-LIMITATIONS.md`。

完整文件在安裝目錄 `resources/docs/`：`USER-GUIDE.md` 是本說明、`KNOWN-LIMITATIONS.md` 是已知限制、`VALIDATION.md` 是實測紀錄、`ATTRIBUTION.md` 是授權與作者致謝、`BUILD-WINDOWS.md` 是原始碼重建流程。原始碼中對應位置為 `docs/integration/`。

1. 執行同版本 `Folia-Mineradio-Setup-…-x64.exe`，選擇安裝位置。開始功能表的名稱為「Folia Mineradio」，設定和原 Folia 分開。
2. 開啟程式，選擇支援的音樂來源，搜尋或匯入自己有權播放的音樂。線上帳號由 Folia 原有來源管理處理，登入狀態不會因切換介面而建立另一份。
3. 把滑鼠移到視窗頂部，在右側鎖定按鈕左邊的體驗下拉選單選擇 Folia、Mineradio 或自訂。選擇後進入播放畫面；歌曲持續播放，音訊節點、進度、音量和佇列保持共用。「設定 → 介面設定 → 播放器體驗 · 自訂」只調整自訂組合，可分別選擇控制介面、歌詞與背景，例如 Folia 歌詞搭配 Mineradio 粒子背景，再從頂部選單切到自訂。
4. Folia 模式使用原歌詞舞臺與控制方式；Mineradio 模式接入原粒子舞臺、鏡頭與歌單瀏覽；自訂模式分別選擇控制介面、歌詞動畫與背景。
5. 暫停、拖曳進度、切歌與音量皆作用在同一個播放核心。各體驗的視覺偏好分別保存，共用歌單、收藏與歌詞快取。

Mineradio 的搜尋、播放按鈕、音量、播放模式和佇列均連到 Folia 核心。首頁／音樂庫按鈕會開啟共用的 Folia 音樂庫；帳號按鈕會開啟共用來源與帳號選單，登入使用 Folia 原有流程。整合版使用獨立資料夾，線上平台請在這個版本登入一次，兩種介面會共享這次登入。來源平台可能限制特定歌曲的地區、會員或試聽；無法播放時依畫面提示處理。原版音質按鈕開啟共用播放設定。

左上角不再顯示浮動的體驗選單，避免蓋住返回按鈕。體驗選單與鎖定、遙控器、全螢幕及視窗控制排在同一列。標題列自動隱藏時，移到頂部即可叫出；操作選單期間會保持可見。點穿模式下僅保留原本的解鎖入口。

舊「Spotify／YouTube」混合頁面及帳號接入已移除，包含 OAuth、登入設定、帳號歌單 API 與建立 Google 憑證的教學。Wallpaper Engine 跟隨外部 YouTube 分頁的功能沿用原有流程。

暫停沿用 Folia 的淡出；淡出結束後時間停止。拖曳進度沿用 Folia 操作，會恢復播放。在 Mineradio 右上角點「DIY」，再點右側視覺控制台按鈕，可調整原版粒子、歌詞、鏡頭與背景參數，內容可用滾輪捲動。自訂體驗與 Mineradio 體驗使用分開的參數儲存區。設定中的外觀備份也包含體驗選擇。

歌曲列表的收藏操作使用共用帳號／本機收藏。「加入歌單」會將選取歌曲加入對應來源的歌單，不先改變正在播放的歌曲。線上歌單需有登入帳號、可寫入歌單及來源平台的修改權限；本機音樂可建立本機歌單。

「播放器直接播放」由本程式提供歌曲音訊及精確進度。「跟隨外部播放器」是 Folia 舞台資料來源的狀態。畫面會顯示音樂、歌詞與時間軸來源，以及桌布資料連線狀態。

搭配 `0.7.17-wallpaper.10.10` 桌布及背景服務時，請啟動歌詞服務，並在桌布動畫選單頂端的播放來源選擇「Folia Mineradio（共用歌詞／時間軸）」。桌布直接使用播放器解析好的逐字歌詞、封面、主題、播放時鐘與音訊分析，不必再次搜尋或語音校正。播放器最小化後仍會傳送進度；短暫資料中斷會直接嘗試播放器的唯讀接口並顯示重連狀態，最多保留十秒的既有時鐘及歌詞，真正斷線後清空。手動切換來源或收到明確停止狀態仍立即更新。桌布的「自動」來源在本播放器有歌曲時優先使用它，暫停時保留歌詞；明確指定 YouTube 分頁或其他應用程式則沿用外部跟隨流程。

桌布本身不播放音樂，可保留既有桌布的螢幕、動畫和參數。兩個本機唯讀接口為播放器 `127.0.0.1:32120` 及桌布服務 `127.0.0.1:3189`；不會將帳號、金鑰或可播放音訊網址送入桌布。這些地址不需要使用者手動設定。AI 預設與使用者既有設定分開；封面配色與歌詞動畫不需要付費 API。

Wallpaper Engine 的效能設定可以在其他程式取得焦點、最大化、全螢幕、播放音訊或螢幕休眠時暫停／停止桌布，播放器仍繼續播放。請在桌布可見且未被暫停時確認同步；回到桌面後會重新取得目前歌曲與進度。若希望音樂播放期間桌布持續更新，可在 Wallpaper Engine「設定 → 效能」依需求調整這些規則。

程式重新啟動後會保留歌曲、佇列、音量和模式設定，歌曲保持暫停，需按播放；精確秒數沿用 Folia 原有行為而未保存。線上歌單的建立／刪除尚未由共用核心提供，請在來源平台處理。

設定與資料位於 `%APPDATA%\Folia Mineradio`。卸載此整合版不會卸載原 Folia、Mineradio 或既有 Wallpaper Engine 桌布。修改版沒有上游自動更新，請使用本機交付的同版本安裝包更新。

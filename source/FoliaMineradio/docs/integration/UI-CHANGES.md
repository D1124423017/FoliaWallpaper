# 本機介面修訂 ui.2

日期：2026-10-16；播放器版本：`0.7.17-integration.4`。

- Folia、Mineradio、自訂的切換改到視窗頂部標題列，位於鎖定按鈕左邊，與遙控器、全螢幕及視窗控制排在同一列。左上角不再有浮動的體驗切換器。
- 設定頁只保留自訂組合的控制介面、歌詞舞台與視覺背景選項。點穿狀態停用體驗切換；選單鍵盤焦點保持可見，不因滑鼠離開頂部而消失。
- 移除標題列、帳號選單、命令面板、整合設定中的舊 Spotify／YouTube 混合頁面入口，解除其全域掛載及開啟時暫停播放的訂閱。
- 共用播放核心與原有支援平台帳號不變。沒有清除使用者的已儲存憑證或設定。
- 依使用者要求移除所有 YouTube 帳號接入，包含已停用的混合帳號 UI、OAuth、帳號歌單服務、Electron IPC 與建立憑證的教學；一併移除同一已停用模組的 Spotify 帳號程式。未更動其他平台帳號與桌布外部來源跟隨。

此修訂的安裝包與原始碼另存本機交付目錄；先前公開的 `license.1` 與 Wallpaper Engine 桌布不在本次變更範圍。

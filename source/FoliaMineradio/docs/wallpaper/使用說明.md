# Folia Wallpaper 原版動畫、Mineradio 粒子背景與自動音訊對齊版（wallpaper.10.8）

這是獨立的 Wallpaper Engine Web 桌布。音樂由原本的播放器播放；桌布不播放音訊，也不需要 Folia.exe 或 NowPlaying 服務。

wallpaper.10.8 加入可選的 Gemini 短音訊校正。到背景服務的「設定 AI 連線.cmd」設定自己的 Gemini 金鑰，再啟用「Gemini 音訊校正」。這是獨立的音訊上傳選項，公開安裝預設停用，啟用 AI 主題不會自動啟用它。啟用後擷取 10 秒系統輸出音訊送到 Google Gemini 3.5 Flash-Lite；不等待 Whisper 模型載入。辨識到的文字與時間仍須和現有歌詞比對，至少跨兩行、8 個匹配字詞及穩定時間才能套用。副歌有多個可能位置時維持歌詞預覽，不猜時間。它是輔助校正，不能保證每個錄音版本、翻唱或變速都能對齊，也不能替不存在的候選歌詞補上歌詞。

Gemini 每首每天最多 2 次、所有歌曲每天最多 20 次（此工具以 UTC 日期計算）；用量計數保存在本機，重新啟動不會重置。一次請求最多等待 15 秒，額度不足時等 5 分鐘才再嘗試；其他失敗仍繼續本機校正。暫停、拖曳、換歌、已通過本機校正或停用音訊上傳會取消未完成請求。已校正版本使用快取，不重复上傳。音訊與辨識文字只在記憶體暫存，不保存錄音；只保存通過驗證的時間校正。系統輸出可能包含其他程式的聲音，這項功能不使用麥克風。

API 用量依 Google 專案方案計算；Free Tier 有模型與額度限制。本工具不啟用付費帳單，也無法替使用者確認帳戶計費方案。可在同一本機設定頁隨時停用；每日上限不是付費帳戶的零費用保證。Gemini 無法使用時，本機首次分析也已提早至 12 秒，後續仍使用較長片段提高辨識率；實際等待還包含歌詞搜尋、片段中何時出現歌聲、模型載入及網路回應。

wallpaper.10.7 將歌詞取得與時間驗證分開。找到歌詞後立即保留並顯示：MV 的時間尚未驗證時，中央顯示可閱讀的「歌詞預覽」，本機音訊分析在背景繼續；校正確認後自動切回所選的 Folia 原版同步動畫。預覽不會依未確認的時間假裝逐字同步，可拖曳捲軸或點下方箭頭閱讀完整歌詞。播放器尚未提供時間軸時也可先閱讀；換歌會清除上一首。這項顯示策略不保證每個 MV 都能自動校正，未通過驗證時會繼續顯示預覽。

## 匯入

1. 開啟 Wallpaper Engine，選「建立桌布」。
2. 將這個資料夾的 `index.html` 拖入編輯器，建立 Web 桌布。
3. 儲存後套用。保留整個資料夾，不能只搬走 index.html。
4. 建議啟用 Wallpaper Engine「設定 → 一般」的媒體資訊整合。背景服務也會獨立讀取 Windows 媒體資訊，不依賴某個螢幕收到 WE 的媒體事件。
5. 在 Spotify 桌面版或 YouTube Music 播放歌曲。歌名／歌手／封面／時間軸是否可用，取決於播放器向 Windows 發布的資料。
6. 雙擊 `C:\Users\lenny\Documents\Codex\2026-10-03\new-chat\outputs\FoliaWallpaper_Lyrics\啟動歌詞服務.cmd`，啟動獨立背景歌詞服務。它不開 Folia，不影響播放器。

背景服務這一版不會自動加入開機啟動，重新開機後需要再啟動一次；「停止歌詞服務.cmd」只停止這個服務。需保留現有 Node.js 24+ 與本地原始碼資料夾，不能只搬走啟動檔。

## 跨播放器偵測

wallpaper.10.4 由背景服務直接列舉 Windows SMTC 媒體工作階段，不限定 Chrome、Spotify 或特定應用程式。優先使用正在播放的工作階段，再依 Windows 目前選定的工作階段選擇；歌名、歌手、專輯、封面、進度與暫停狀態直接交給 Folia。Chrome 的 YouTube 連接擴充功能仍可補上更精確的 HTML 影片時間，只有同一歌名與歌手的分頁可提供此時間軸。移動至其他螢幕或重載後不需等待下一次 WE 歌名事件。

同時讀取所有啟用的喇叭／耳機輸出装置音量，不限播放器，也不使用麥克風或保存音訊。未提供歌曲資訊的程式播放聲音時顯示「已偵測到聲音 · 此程式未提供歌曲資訊」，畫面仍使用 WE 的實際頻譜；WE 頻譜未送達時以真實输出音量驅動 audioPower，不編造頻段或歌詞時間。聲音偵測包含影片、遊戲、通知及通話，單靠音量無法判斷它是不是音樂或辨認歌名。只有取得歌名、正確錄音歌詞與時間軸才能同步歌詞；沒有時間軸時仍明確提示。Windows SMTC 需要 Windows 10 1809 或更新版本，應用程式需發布媒體資訊。獨占音訊模式是否可讀音量取決於音效裝置的硬體音量表。

停止背景服務或媒體工作階段消失時，四秒內停止使用舊進度並清除已失效的歌曲，不會讓舊歌一直繼續播放。

背景服務在取得正在播放的歌曲後立即搜尋歌詞，不等待桌布繪製；桌布隱藏或被 WE 暫停時，搜尋與本機時間校正仍依播放器的真實狀態運作。真正暫停音樂、換歌或失去時間軸才停止該歌曲的分析。已驗證的錄音版本校正最多保留 32 首，只記錄歌詞來源、時間校正與歌詞摘要；同版本再次播放可重用，歌詞內容或時間戳改變時重新驗證。

瀏覽器的 Windows 媒體工作階段被其他頁面的泛用標題取代、且沒有歌手時，優先使用 Chrome 連接回報的正在播放 YouTube 歌曲。這不會覆蓋 Spotify、VLC 等獨立播放器的播放資料；多個播放器同時發聲仍可能影響本機校正。

## 使用

- 新增「視覺系統」：選「Mineradio × Folia 歌詞」使用原版 Mineradio 粒子背景，歌詞仍由所選的 Folia 原版樣式繪製。右下角選單或 Wallpaper Engine 右側均可切換。
- 「Mineradio 動畫」提供 Emily 封面粒子、滾筒、星球、唱片、星河、安魂、月蝕聖環、雨幕霓虹、折光蝶群、深海綻放共 10 種動畫，另有「虛空」安靜背景。可調粒子反應、速度、大小、光暈與透明度；一起包含在參數匯出／匯入。原版粒子著色器、幾何、封面分析及切換動畫直接使用上游程式碼；相機使用原版預設構圖，未移植完整播放器的電影鏡頭操作。
- Mineradio 以 30 FPS、最多 260 萬像素繪製，暫停時 5 FPS，桌布被 WE 暫停時停止。歌詞與背景同時繪製會增加 GPU 負載，必要時降低光暈或切回 Folia。
- Sonic Topography／Sonic Workshop 兩個第三方「音域回響」預設未收錄，避免把不相容或尚未確認的授權放入公開包。Mineradio 的 GPLv3 與 Three.js MIT 授權、原作者資訊保留在 mineradio/。完整可重建的修改版原始碼發佈時也必須保留 dev/wallpaper/mineradio/。

- Wallpaper Engine 右側桌布設定的「歌詞樣式」沿用 Folia 的繁體中文名稱，可切換全部 14 種內建模式：心象（Cadenza）、群唱（Cappella）、迴環（Claddagh）、流光（Classic）、鏡臺（Diorama）、浮名（Fume）、繪光（Lumiere）、莫奈（Monet）、雲階（Partita）、時計（Pendolo）、商籟（Sonnet）、靜止（Still）、凝彩（Tempera）、傾訴（Tilt）。靜止是原版刻意設計的靜態模式；其他模式的效果各有不同，同一時間顯示所選的一種。
- 「背景型別」可選通用（Common）、隱現（Latent）、莫奈（Monet）、漫遊（Nomand）、空（Sora），預設為 Folia 原版的隱現。名稱直接取自原版繁體中文詞典。部分 Visualizer 有自己的舞臺背景，會依原版設計蓋住共用背景。外部 URL 背景與模組管理未接入。
- 可調整歌詞大小、音訊反應強度和歌曲資訊，也可在桌面右下角開啟動畫設定選單。
- 預設主題來源是「封面取色」，直接使用 Folia 原版取色與亮／暗配色產生器，不使用 AI API。
- 「歌詞時間校正」正值會讓歌詞提早，例如 +500 表示提早半秒；負值會延後。
- 暫停、繼續、拖曳、換歌在收到播放器事件後自動同步，不需要選擇歌詞。
- 找不到同步歌詞時保留封面與背景；未提供時間軸時會明確提示，避免假裝知道進度。
- 未播放音樂時是安靜的待機狀態。
- 開啟「示範模式」可先看原版動畫，使用原創測試文字與模擬頻譜，不是正在播放的歌曲。看真實音樂前需關閉。
- 直接用瀏覽器開啟只提供預覽；它沒有 Wallpaper Engine 的系統媒體 API。預覽示範可在網址加入 `?demo=1`。部分瀏覽器不允許 file:// 載入模組，請在 WE 匯入，或用本機 HTTP 伺服器預覽。

## 桌面動畫設定選單

多螢幕滾輪轉接會自動偵測 Wallpaper Engine 在 IPv4／IPv6 本機位址上的 Folia 頁面。每張桌布分別保存選單範圍與事件佇列，依該螢幕的實際座標轉接；移動或重新載入桌布後會自動重新連線。其他螢幕可使用別的桌布，不需把 Folia 固定在主要螢幕。背景歌詞服務與 CEF DevTools 連接埠仍需保持啟用。

wallpaper.10.3 提供 Windows 滾輪轉接。Web 桌布未將實際滾輪傳入，因此此功能由既有背景服務提供：雙擊配套工具的「啟用桌布滾輪.cmd」，並將 WE「設定 → 一般 → CEF DevTools 連接埠」設為 3192。只在這張 Folia 桌布選單開啟且游標位於選單上、沒有其他程式蓋住時，轉送滾輪到本機 CEF 頁面；關閉選單或停止服務即停止原生轉接。動畫下拉清單也使用相同轉接。只暫時處理滾輪增量，不記錄游標歷史或鍵盤輸入，不改變 Windows 其他程式的輸入。可用「停用桌布滾輪.cmd」停用。發佈用工具預設停用，需使用者自行啟用。原生程式的完整原始碼在 dev/wallpaper/input/，由 Windows 內建 .NET Framework 編譯器重建，不需管理員權限或另行下載執行檔。

wallpaper.10.2 修正選單捲動區域的彈性高度，並在底部固定顯示「向上／向下」按鈕。桌面環境沒有傳入滑鼠滾輪時，仍可點按鈕捲到全部設定；也可拖曳加寬的右側捲軸。取得鍵盤焦點後可用 Page Up／Page Down、Home／End 操作。下拉選單有獨立捲軸，不會把外層設定一起捲走。

wallpaper.10.1 改用 Folia 原版 HTML 選擇器，修正已重現的 WE 內嵌瀏覽器在繪製桌面下拉選單時崩潰。所有動畫與設定保留。桌布以單一傳統腳本載入，並固定延遲載入素材與歌詞解析器的相對路徑。

1. 點桌面右下角的圓形調整按鈕，開啟「動畫設定」。右上角叉號關閉；有鍵盤焦點時也可按 Esc。
2. 點歌詞樣式／背景名稱展開原版選單，或用兩側箭頭切換。所有 14 種模式及 5 種背景仍由原版 renderer 繪製。
3. 歌詞樣式右側的「平靜／標準／混亂」按鈕循環切換動畫強度；「通用」頁也可選「依主題設定」。混亂會影響原版動畫幅度和節奏，各樣式的反應不同。
4. 「歌詞」及「背景」分頁直接顯示 Folia 原版詳細面板，可調整鏡頭、文字動勢、背景氣線、幾何、光暈、排版等該樣式支援的參數。心象與靜止在原版沒有額外面板。「重設此樣式參數」只重設目前樣式。
5. 「通用」頁提供主題來源、亮暗、歌詞大小／透明度、音訊反應、時間校正及資訊顯示。Cappella 頭像／表情包、Monet 肖像／背景圖片可從其原版面板匯入，在此桌布的 IndexedDB 保存；Folia 本體的素材不會自動同步。

桌面選單的調整自動保存在這張桌布的瀏覽器儲存空間，重新載入仍保留。Wallpaper Engine 右側設定面板更改某個值時，該值重新取得優先權；其他桌面調整保留。桌面選單無法反向更新 WE 右側面板的顯示值。「使用 Wallpaper Engine 設定值」會清除桌面對基本選項的覆寫；樣式細部參數需在各分頁單獨重設。

若右下角無法點擊，可在 WE 右側桌布設定勾選「開啟桌面動畫選單」。若之前勾選過，先取消再勾選，即可重新開啟。隱藏右下角按鈕後也能用這個入口恢復；需允許 Wallpaper Engine 接收桌面滑鼠互動。

「匯出參數」保存目前的動畫／背景參數；「匯入參數」接受匯出 JSON 或含 Folia `folia-theme://` 配置碼的 TXT。只套用動畫、背景和相關基本參數，不套用主題顏色／字體，也不搬入圖片包或 API 金鑰。圖片需分開匯入。檔案選取與下載依 WE 內嵌瀏覽器的支援情況；已在 Chrome 預覽驗證。

## Chrome 的 YouTube 顯示「播放器尚未提供時間軸」

歌名與播放時間是分開的資料。播放器只有提供歌名時，桌布不能知道目前唱到哪句，這與 AI 無關。

1. 啟動上述本機背景服務。
2. Chrome 開啟 `chrome://extensions`，開啟右上角「開發人員模式」。
3. 選「載入未封裝項目」，選擇 `C:\Users\lenny\Documents\Codex\2026-10-03\new-chat\outputs\FoliaWallpaper_Chrome` 整個資料夾。
4. 重新整理 YouTube／YouTube Music 分頁，繼續播放。

此擴充功能只讀取 YouTube 的標題、頻道／歌手、HTML 影片的真實進度、時長、速度及播放狀態，傳給本機服務，不讀取帳號、不控制音樂。暫停／播放／跳轉／緩衝／速度改變會立即回報，由本機事件串流推送到桌布，不再等下一次輪詢；播放時每秒校準。桌布在兩次校準之間依實際播放速度推進 MotionValue，不透過逐幀 React 更新。事件串流中斷時會自動重連並使用輪詢備援；超過四秒沒有新資料就停止使用舊時間軸。

只有與桌布顯示歌名完全一致的分頁能提供時間軸；多個分頁會優先使用正在播放的分頁。關閉分頁或服務後，不會持續假造進度。Spotify 等能提供原生时间軸的播放器仍可直接使用 WE 資料。更新此擴充功能後需在 Chrome 擴充功能頁按重新載入並重新整理音樂分頁。

## AI 主題連線

雙擊 `FoliaWallpaper_Lyrics\設定 AI 連線.cmd`，在本機頁面選 Gemini 或 OpenAI 相容服務並填入自己的 API 金鑰。已有 Folia AI 設定時會先沿用；新金鑰以 Windows 使用者 DPAPI 保護，存放於 `%APPDATA%\FoliaWallpaper\ai-config.json`，不寫入桌布或診斷資訊。不要將金鑰貼到聊天裡。

WE「主題來源」選 AI 時，使用 Folia 原版提示詞、連線程式與主題解析器，最多傳送 2,000 字元歌詞，產生亮／暗配色、字詞顏色及圖示；「主題明暗」可切換兩份結果。原版動畫仍由 VisualizerRenderer 繪製。未設定金鑰、等待歌詞或 AI 失敗時使用封面取色，歌詞動畫本身不需要 AI。

快取保留最近 64 組主題。同歌曲、歌詞、連線設定會重用主題；換歌會取消已無使用者等待的舊請求，舊結果不會覆蓋下一首。設定更新後約 15 秒會再嘗試。AI 連線失敗時只輪詢本機設定狀態，不反覆呼叫付費 API。

API 費用依服務、模型與專案方案。Gemini 可先選 Free Tier 並保持未啟用付費帳單，限額以 Google AI Studio 為準；OpenAI API 與 ChatGPT 訂閱分開計費。不使用 AI 時可選「封面取色」，不會送出 AI 主題請求。這版只接入 AI 主題，不包含 AI 自動分詞或 Automix。

## 歌詞來源與限制

背景服務直接重用 Folia 原版 `autoMatchBestLyric`、來源優先序與解析器，跨網易雲、AMLL、QQ、酷狗搜尋；保留真正的逐字時序，沒有逐字版本才回退逐行版本。桌布再以 AMLL 名稱搜尋與 LRCLIB 同步 LRC 補足。一般播放器會驗證歌名、歌手和已知時長。AMLL 單純名稱搜尋沒有完整歌曲時長，診斷中會標為 duration-unverified。逐行歌詞的字內動畫由 Folia 原版解析器估算，不代表真實逐字時間。

一般歌曲依 Folia 原版配對器驗證歌名、歌手及錄音長度，直接使用原版歌詞時序。嚴格版本配對失敗時，會再找同名同歌手的歌詞候選，但候選只是文字和原版逐字時間的依據，不立即當成影片同步歌詞。畫面會提示正在自動對齊，保留封面及背景。

wallpaper.7 修正酷狗公開歌詞搜尋的舊版 `duration` 欄位轉接，避免把缺少長度驗證的專輯版當成 MV 的相同錄音。已知播放器長度而候選沒有長度時，不視為已驗證版本；AMLL 名稱回退遇到明顯過長的 MV 差異也不直接套用。歌曲長度更新時會先清除舊版本歌詞，避免等待期間繼續顯示錯誤版本。

也修正 Classic 在暫停時跳到新段落後，字詞等待下一次時間更新才出現的問題；它現在從目前進度初始化字詞狀態，原本的動畫、排版及 easing 保留。

wallpaper.8.1 已移除單首 MV 的固定偏移規則。你已同意使用本機系統輸出音訊與下載模型：歌曲版本不一致時，背景服務會用 [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 的本機 small 模型辨識一段歌聲，將辨識詞語和原版歌詞作有界序列配對，自動估算時間差。使用 RTX 3060 Ti 可用的 GPU 執行環境；不可用時回退 CPU int8、兩個執行緒。錄音留在有限的記憶體視窗，不保存音訊檔案，也不呼叫付費 AI API；AI 封面主題仍停用。

只有歌詞候選存在、播放器時間軸可用且正在播放時才擷取系統輸出；不使用麥克風。不同版本才啟用辨識，版本已匹配的普通歌曲直接用原時間標記。待機超過 90 秒會釋放模型程序。首次或跳轉後需要收集約 20 秒的片段，再加上辨識時間；換歌會清除舊辨識資料，舊結果不得覆蓋新歌。辨識後仍使用原播放器進度驅動畫面；保留原版逐字間隔，分段偏移可處理辨識到的額外插入段落。

自動檢查各個喇叭／耳機的輸出，最多八個装置，不限定 Windows 預設輸出。不同装置的辨識文字只在記憶體分開比對，沒有可靠匹配時不套用校正；找到匹配後優先處理該輸出。相鄰片段合併為最多 45 秒、240 個詞的比對視窗，以降低重複副歌的歧義。歌聲篩選沿用 Whisper 的靜音判定，保留仍有足夠辨識信心的歌聲。音訊與辨識文字均不保存、不上傳；片段仍可能包含其他同時播放的聲音。

重複副歌無法判定是哪一段、其他聲音干擾、語言或伴奏造成辨識不可靠時，會继续聆聽，不隨意套用位置。不能保證所有歌曲都能取得歌詞或被可靠辨識；此流程自動運作，不需要逐首增加程式規則。聲音重疊的程式也會進入 Windows 系統混音，使用時宜保持單一主要音樂來源。停止「背景歌詞服務」會停止本機辨識。

這些來源需要網路。沒有訂閱平台 API 或 OAuth 登入要求；不會取得你的帳號、密碼、歌單或音訊檔案。搜尋時只送出歌曲資訊。背景服務只綁定本機 `127.0.0.1:3189`，只接受有限長度的歌曲資訊，不提供任意網址代理。

服務未啟動時，若 AMLL / LRCLIB 也沒有結果，會顯示「背景歌詞服務尚未啟動」，每 15 秒重新檢查。QQ 目前可能回應 API 2001；這時會繼續嘗試網易雲、AMLL 和酷狗，不能保證每個來源或每首歌都有可用歌詞。

音訊反應採用 Wallpaper Engine 系統混音，其他程式的聲音也可能影響。頻段由 64 格左右聲道校準成 Folia 的 0–255 值，不等同原版 WebAudio FFT 或分離人聲。

YouTube 的官方 MV／動態歌詞標記、歌手／歌名組合標題、Topic 頻道、中英雙語標題、書名號歌名、標題末尾的宣傳歌詞及演員資訊會先解析後搜尋；Live／Remix 等錄音版本標記會保留。資料庫沒有對應同步歌詞的歌曲仍會顯示「未找到合適的同步歌詞」，不會拿其他歌的歌詞替代。含額外劇情的 MV 可能比專輯錄音長，不能單憑同名就保證同步。

## 與本地 Folia 0.7.17 的功能對照

### 選擇播放來源（wallpaper.10.5）

wallpaper.10.6 修正：Chrome／Edge 的應用程式選項標示為「整個瀏覽器（可能切換分頁）」，單一分頁請選「網頁」項目。暫停／背景分頁的選項保留三分鐘，但超過四秒的時間軸停止使用，避免憑舊進度推測播放。清單顺序不隨其他頁面播放／暫停而跳動。手動選擇立即通知本張桌布並使先前的自動回報失效，等待或離線時不回退至其他分頁。

Chrome 連接 1.2.1 在要使用的分頁點擴充功能按鈕「指定此分頁為 Folia 播放來源」，會連接並直接鎖定該分頁。重複點擊會重新回報，無須重新整理正在聽的歌曲；關閉已連接分頁時會移除選項，保存的選擇仍等待同一來源。此次更新沒有增加權限。更新擴充功能後若舊分頁未連線，在該分頁點此按鈕即可恢復；也能重新整理 YouTube。

點桌布右下角的動畫設定按鈕，選單頂端的「播放來源」可以選自動偵測、指定網頁或 Windows 應用程式。Wallpaper Engine 的屬性面板也有「開啟播放來源選擇」入口。這是獨立桌布的精簡設定，沒有載入 Folia 本體的命令面板。

先在目標分頁／程式播放歌曲，讓它出現在清單，再選該來源。選擇保存在本機背景服務的 `media-source.json`，套用到此電腦的 Folia 桌布；不混入視覺配置匯出。換歌、暫停、拖曳進度都跟隨選定來源。來源關閉／失去連線時顯示未連線，不自動改用其他播放程式。要恢復自動偵測，可重新選「自動偵測」。重新開啟的網頁可能是新分頁，需再選一次。

Chrome YouTube／YouTube Music 分頁由原有連接自動出現在清單。其他網頁：將更新後的 Chrome 擴充功能重新載入，在要連接的播放網頁點「Folia Wallpaper · 網頁播放來源」擴充功能按鈕。它透過 `activeTab` 僅在你點擊的頁面執行，讀取 HTML 音訊／影片的時間、播放狀態，以及網頁提供的媒體歌名／歌手；不要求讀取所有網站。更換網站或重新整理後可能需要再點一次。跨來源 iframe、直播／沒有有限時長的影片或特殊播放器不一定能連接。未提供歌名的網站可能只提供網頁標題，無法保證找到歌詞。

Windows 應用程式只列出提供系統媒體資訊的播放器，沒有歌曲工作階段的程式不會出現在清單。選擇來源固定的是歌曲資訊與時間軸；Wallpaper Engine 頻譜和本機音訊校正仍可能含其他同時播放的聲音，並非單一程式音訊隔離。選定來源暫停／關閉時會停止它的校正。

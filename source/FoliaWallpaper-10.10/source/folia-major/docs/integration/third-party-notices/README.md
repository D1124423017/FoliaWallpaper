# 官方授權補件

此目錄保留 npm 發布包未內附的授權通知，供修改版原始碼與 Windows 安裝包離線提供。文件保持原文，不能翻譯或刪減第三方通知；每份官方來源、精確版本、下載日期和 SHA-256 都列在 `NOTICE-SOURCES.json`。

- ONNX Runtime 1.30.0：官方 `v1.30.0` 標籤對應 commit `f2c39fe2f838cf35ce7da92824f5a5e3ee6e88a7` 的 LICENSE 和完整 ThirdPartyNotices。Microsoft 官方通知是整個專案的聯集，不表示每個列出的第三方元件在本播放器中均啟用。
- React Three Fiber 9.8.1：官方 npm metadata 的 gitHead `53ec672ac4a7189711766b87ece18889abbb32d4` 所對應 LICENSE。
- GSAP 3.15.0：官方 npm 發布 metadata 的授權名稱為 Standard No-Charge License，指向 `https://gsap.com/standard-license`；此處保留它在 2026-10-13 導向的官方 Standard License 頁面原始 HTML。此 HTML 是文件，不加入播放器 UI 或執行腳本；離線查看時外部網站樣式可能不完整。原版 `gsap.min.js` 中的版權及授權頭註另行保留。

GSAP 不是 MIT。各元件分別保留其原始授權，不能用 Folia 或 Mineradio 的 GPL／AGPL 授權名稱覆蓋第三方條款。

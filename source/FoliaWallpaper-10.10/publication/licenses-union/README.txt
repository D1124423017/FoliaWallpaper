This directory retains available original notices and licenses, with unresolved source-version notice gaps explicitly listed in NOTICE-GAPS.md, notice-gaps.json and notice-coverage.json. Publisher metadata is not a substitute for license text and is never counted as a retained license document. The dependency manifest is a superset of build, type, test and runtime dependencies; not every listed package is delivered at runtime. Usage labels come from source imports and installed dependency graphs, not a minifier/tree-shaking proof. Type-definition and build-or-test-only entries should not be described as player runtime features. Official documents and hashes are recorded in official-notice-sources.json; versionEvidence explicitly identifies any project-level notice from a different source revision. Such entries have project-notice-only status, not original-version-complete status.

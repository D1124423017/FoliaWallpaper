# Folia Wallpaper 配套工具（Windows 10/11，x64）

本工具搭配 Folia Wallpaper，音樂仍由你原本的播放器播放，不需要啟動 Folia.exe。
先解壓縮整個 `FoliaWallpaperTools` 資料夾到自己可寫入的位置，例如「文件」。不要直接在 ZIP 內執行，也不要放入 Program Files。

1. 雙擊 **啟動歌詞服務.cmd**。工具已附 Node.js，不必另裝 Node.js 或下載原始碼。出現「背景歌詞服務已啟動」後，可關閉命令視窗；服務留在背景。
2. 在 Wallpaper Engine 啟用媒體資訊整合、套用 Folia 桌布，關閉「示範模式」。
3. Chrome 的 YouTube／YouTube Music 使用者：開啟 `chrome://extensions`，開啟「開發人員模式」，按「載入未封裝項目」，選本工具的 **chrome** 資料夾。再重新整理音樂分頁。一定先完成第 1 步，工具才會產生本機連接設定。
4. Spotify 等播放器須向 Windows 提供歌曲及時間軸；實際支援情況取決於播放器。
5. 若歌曲版本不同而需要校正，雙擊 **啟用本機音訊校正.cmd**，閱讀說明、輸入 Y。工具會在此資料夾安裝獨立 Python 與套件、下載 Whisper small 模型，不修改系統 PATH。首次需網路和數 GB 空間。
6. 有 NVIDIA GPU 時可再執行 **啟用NVIDIA加速.cmd**；會另下載 GPU 套件。GPU 不可用時仍使用 CPU。

本機音訊分析預設停用。啟用後只分析目前預設喇叭的系統混音，不使用麥克風、不儲存錄音、不將音訊傳送至 API。其他同時播放的聲音也可能影響辨識。首次或跳轉後需約 20 秒可辨識歌聲，再加上處理時間；找不到候選歌詞或辨識不可靠時仍可能無法同步。

**停用本機音訊校正.cmd** 關閉分析，**停止歌詞服務.cmd** 停止整個服務，**查看服務狀態.cmd** 顯示診斷。重新開機後需再執行啟動檔；本版不自動新增開機啟動項目。

服務只綁定 `127.0.0.1:3189`。Chrome 連接設定由每台電腦自行產生；`.data` 中的 token、日誌與執行資料不要公開分享。歌詞搜尋會把歌名、歌手等資訊送至第三方來源；本機音訊不會送出。預設為封面配色，不需要付費 AI API。

若提示另一份 Folia 服務使用同一連接埠，先用原工具停止服務，再啟動此版；本工具不會自行關閉別的程序。更新時停止此工具、解壓縮新版覆蓋同一資料夾，保留 `.data` 及 `audio` 中已下載的環境與模型。Chrome 擴充功能更新後需按「重新載入」並重新整理音樂分頁。

## 可選 AI 主題

執行「設定AI連線.cmd」，在本機設定頁填入自己的 Google Gemini 或 OpenAI 相容 API 金鑰，再將桌布的「主題來源」改為 AI。此功能會傳送最多 2,000 字元的歌詞文字至所選供應商；不傳送播放音訊。金鑰以 Windows 使用者 DPAPI 加密存於自己的 AppData，不寫入桌布、原始碼或本工具包。

預設仍為封面配色，歌詞與本機音訊同步不需要雲端 AI。Gemini 專案維持 Free tier、使用具有免費額度的模型時受免費配額限制；若自己啟用付費帳單或其他服務，費用依供應商計算。本工具不會替你啟用付費帳單。

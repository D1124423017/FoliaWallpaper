# Folia Wallpaper｜繁體中文同步歌詞桌布

這是基於 Folia 的非官方 Wallpaper Engine Web 桌布，直接重用原版的歌詞動畫與背景。

## 安裝與使用

1. 解壓縮整個 FoliaWallpaper 資料夾，將 `index.html` 匯入 Wallpaper Engine 的「建立桌布」。保留整個資料夾。
2. 啟用 Wallpaper Engine 的媒體資訊整合。使用真實音樂前，關閉桌布設定的「示範模式」。
3. 下載配套工具，依工具包中的「使用說明.md」啟動背景歌詞服務。Chrome YouTube／YouTube Music 再載入其中的 chrome 擴充功能。
4. 由原本的播放器播放歌曲；桌布接收歌名、封面、時間軸與系統頻譜，不播放音訊、不需要 Folia.exe。

工具與完整原始碼：https://github.com/D1124423017/FoliaWallpaper/releases/tag/wallpaper.8

## 中文設定

- 歌詞樣式：心象、群唱、迴環、流光、鏡臺、浮名、繪光、莫奈、雲階、時計、商籟、靜止、凝彩、傾訴。
- 背景型別：通用、隱現、莫奈、漫遊、空。
- 可調整歌詞大小、音訊反應強度、歌曲資訊與封面顯示。
- 預設封面配色，不使用付費 AI 主題 API。

完整歌詞功能需要配套工具，僅訂閱桌布不會自動安裝背景服務或瀏覽器擴充功能。選用本機音訊校正時需先同意系統音訊分析並下載模型。辨識品質與歌詞來源可能受錄音版本、其他聲音或連線影響，不保證所有歌曲都有同步歌詞或真正的逐字時間。
